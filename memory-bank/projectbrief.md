# Project Brief: OrientationMada

## 🎯 Objectif Principal

OrientationMada est une API d'annuaire universitaire en ligne dédiée à Madagascar qui vise à démocratiser l'accès à l'information sur l'enseignement supérieur. Le projet permet aux étudiants de rechercher des établissements et formations sans se déplacer de ville en ville, tout en bénéficiant de suggestions personnalisées via un chatbot IA pour les orienter selon leurs besoins et parcours.

## 📋 Description du Projet

Cette API centralise les informations sur l'écosystème universitaire malgache et fournit trois services principaux :

1.  **Système de recherche avancée** : Recherche d'établissements et de formations avec des options de filtrage géographique et par critères spécifiques.
2.  **Moteur de recommandations** : Suggestions basées sur les statistiques d'inscription et les profils des étudiants.
3.  **Chatbot intelligent** : Un agent conversationnel utilisant l'IA pour guider les utilisateurs vers les formations et établissements les plus pertinents pour leur situation.

Les clients cibles incluent les étudiants, les parents, les conseillers d'orientation, ainsi que les applications web/mobiles et autres services éducatifs.
